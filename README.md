# Akshar Sweets & Farsan – Mobile & Web Platform

A professional, responsive Gujarati Sweets & Farsan customer ordering platform featuring pure Gir Cow Desi Ghee mithai and fresh daily farsan.

## Features
- **Mobile-First & Desktop Adaptive**: Seamless fluid layout on mobile & tablet, transforming into a sidebar desktop experience on wide displays.
- **Product Catalogue**: 35 realistic authentic Gujarati & Indian sweets and snacks across 6 categories with weight-based variants (`250g`, `500g`, `1kg`).
- **Cart & Simulated Checkout**: Live cart calculations, free express delivery tracker, coupon system (`FESTIVE20`), and simulated OTP verification.
- **Order Lifecycle & Tracking**: Real-time order tracking stepper (`Placed` → `Accepted` → `Preparing` → `Out for Delivery` → `Completed`).
- **GST Invoicing & Receipts**: Instant itemized tax invoice & kitchen dispatch slip with printable layout.
- **Wholesale Portal**: B2B bulk quotation requests (RFQ) for caterers and event planners.

## Tech Stack
- Pure Semantic HTML5
- Responsive Modern CSS3 (Neo-Bazaar Design System)
- Vanilla JavaScript (Shared State Store & LocalStorage persistence)
